# 캐릭터팩 사용·제작 가이드

현재 NookBit에서 가져오는 캐릭터팩은 **이미지팩(ImagePack v1)**이에요.
캐릭터 그림, 애니메이션, 화면에 놓일 기준점과 선택적인 말풍선 모양을 담아요.
팩 자체가 파일을 옮기거나 프로그램을 실행하지는 않아요.

## 팩을 사용하는 방법

1. 캐릭터 설정에서 **팩 폴더 가져오기…**를 누르세요.
2. `imagepack.json`과 그림 파일이 함께 들어 있는 폴더를 선택하세요.
3. 가져온 팩을 목록에서 선택하고 **표시 크기**를 조절하세요.

가져오기는 원본 폴더를 변경하지 않고 앱에 복사해 보관해요.
선택한 팩과 개인별 표시 크기는 다음 실행 때도 기억해요.
가져오기에 실패하면 오류 안내를 확인하세요. 현재 캐릭터는 그대로 유지돼요.
ZIP 파일 직접 가져오기는 아직 지원하지 않으니 먼저 압축을 푸세요.

## 팩 폴더의 구성

```text
내 캐릭터팩/
  imagepack.json
  images/
    character.png
```

`imagepack.json`은 어떤 그림을 어떤 상황에서 보여줄지 설명하는 설정 파일이에요.
그림 파일은 팩 폴더 안에 넣고, 설정 파일에는 `images/character.png`처럼
그 폴더를 기준으로 한 경로를 적으세요. 외부 경로나 `..`는 사용할 수 없어요.

## 그림은 PNG로 준비하세요

배경이 투명한 PNG를 권장해요. 그림 크기를 128픽셀로 고정할 필요는 없어요.
512픽셀처럼 큰 그림도 표시 기준을 정해서 사용할 수 있어요.

- **개별 PNG**: 한 장을 한 프레임으로 사용해요. 프레임마다 파일을 따로 둘 수 있어요.
- **아틀라스**: 여러 프레임을 한 PNG에 모아요. 같은 크기의 격자 또는 직접 지정한 사각 영역을 사용해요.

두 방식을 한 팩에 섞어도 돼요. 도트 그림은 `nearest`, 부드러운 그림은
`linear` 표시를 선택할 수 있어요. 회전시켜 넣은 아틀라스 영역은 지원하지 않아요.

## 기준점과 크기 이해하기

**피벗(pivot)**은 캐릭터가 화면에 놓이는 기준점이에요.
서 있는 캐릭터라면 발밑 가운데를 기준으로 잡으면 이해하기 쉬워요.
이미지의 왼쪽 위부터 오른쪽으로 X, 아래쪽으로 Y가 증가해요.

피벗 좌표는 원본 픽셀 수가 아니라 **표시 기준 단위**예요.
예를 들어 `pixelsPerUnit: 4`이면 원본 4픽셀이 표시 기준 1단위예요.
512×512 그림은 128×128 기준 크기가 되고, 피벗 `(64, 112)`는
원본 그림의 `(256, 448)` 지점을 가리켜요.

팩에는 기본 피벗을 두고 프레임마다 따로 바꿀 수도 있어요.
걷기와 걸터앉기처럼 자세가 다른 그림도 적절한 기준점을 정할 수 있어요.
아틀라스에서는 전체 PNG가 아니라 **해당 프레임의 왼쪽 위**를 기준으로 계산해요.
그림 여백을 잘라냈다면 피벗도 그만큼 조정해야 해요.
사용자가 설정하는 표시 크기는 이 기준 위에 추가로 적용돼요.

## 상황과 애니메이션

프레임은 보여줄 그림 한 장, 애니메이션은 프레임과 재생 시간을 나열한 것이에요.
한 프레임만 쓰면 정지 그림도 사용할 수 있어요.
아래 세 상황 연결은 반드시 있어야 해요. 같은 애니메이션을 연결해도 돼요.

- `resting`: 평소 쉬고 있을 때
- `calling`: 사용자에게 주의를 요청할 때
- `working`: 작업 중일 때

각 프레임의 시간은 밀리초예요. 1000은 1초예요.
반복 재생을 끄면 재생이 끝난 뒤 마지막 그림을 유지해요.

## 한 장짜리 최소 팩 예제

128×128 PNG를 `images/character.png`로 준비하고, 아래 내용을
`imagepack.json`으로 저장하면 세 상황 모두 같은 그림을 보여줄 수 있어요.
설정 파일은 UTF-8로 저장하세요. `id`는 영문·숫자·점·밑줄·하이픈으로 정하세요.

```json
{
  "schemaVersion": 1,
  "packType": "imagepack",
  "id": "my.character",
  "name": "내 캐릭터",
  "version": "1.0.0",
  "display": {
    "referenceSize": { "width": 128, "height": 128 },
    "pixelsPerUnit": 1,
    "pivot": { "x": 64, "y": 120 },
    "filtering": "linear"
  },
  "sources": [
    { "id": "picture", "kind": "image", "file": "images/character.png" }
  ],
  "frames": [
    { "id": "pose", "sourceId": "picture", "region": { "type": "image" } }
  ],
  "animations": [
    { "id": "still", "loop": true, "steps": [ { "frameId": "pose", "durationMs": 1000 } ] }
  ],
  "bindings": [
    { "cueId": "resting", "animationId": "still" },
    { "cueId": "calling", "animationId": "still" },
    { "cueId": "working", "animationId": "still" }
  ]
}
```

## 아틀라스를 쓰고 싶다면

128×128 프레임 두 장을 가로로 붙인 256×128 PNG를
`images/sheet.png`로 준비하세요. 위 예제의 `sources`와 `frames`를
아래 항목으로 바꾸면 첫 칸을 같은 `pose` 프레임으로 사용할 수 있어요.
나머지 항목은 그대로 두세요.

```json
"sources": [
  { "id": "sheet", "kind": "atlas", "file": "images/sheet.png",
    "grid": { "frameWidth": 128, "frameHeight": 128, "columns": 2, "rows": 1 } }
],
"frames": [
  { "id": "pose", "sourceId": "sheet", "region": { "type": "cell", "index": 0 } },
  { "id": "pose2", "sourceId": "sheet", "region": { "type": "cell", "index": 1 } }
]
```

칸 번호는 0부터 시작하고 왼쪽에서 오른쪽, 그다음 줄 순서예요.
움직이게 하려면 애니메이션의 `steps`에 `pose`와 `pose2`를 순서대로
넣고 각 그림의 시간을 정하세요. 시간은 16~60000밀리초 범위예요.
프레임마다 피벗을 바꾸려면 해당 프레임에 `"pivot": { "x": 64, "y": 120 }`을 추가하세요.

## 말풍선은 기본 제공 모양을 써도 돼요

말풍선 설정을 생략하면 앱의 기본 말풍선이 나와요.
선택적으로 `bubble` 설정에서 말풍선이 붙는 위치와 모양을 바꿀 수 있어요.

- `attachment`: **캐릭터 기준점에서** 말풍선이 붙을 지점까지의 거리예요. 캐릭터 표시 크기의 영향을 받아요.
- `pivot`: **말풍선 내부에서** 맞닿을 지점이에요. 왼쪽 위 `(0, 0)`, 오른쪽 아래 `(1, 1)`이며 보통 꼬리 끝으로 잡아요.

두 지점이 만나도록 말풍선을 배치해요. 화면 밖으로 나가면 화면 안에 보이도록
위치를 보정할 수 있어요. 아래 설정은 기본 말풍선을 캐릭터 기준점 위에 붙이는 예제예요.
이 `bubble` 항목을 설정 파일의 최상위에 추가하세요.

```json
"bubble": {
  "attachment": { "x": 0, "y": -120 },
  "pivot": { "x": 0.1, "y": 1 },
  "skin": { "kind": "default" }
}
```

직접 만든 말풍선 PNG도 사용할 수 있어요. 이때는 배경 그림과 표시 크기,
글자 영역과 버튼 영역을 지정해야 해요. 글자 영역과 버튼 영역은 겹치면 안 돼요.
현재 말풍선 글자는 밝은 색이므로 글자 뒤쪽을 충분히 어둡게 만들어 주세요.
말풍선 아틀라스·애니메이션·자동 늘어나는 이미지 테두리는 아직 지원하지 않아요.

## 현재 지원하지 않는 기능

독립적인 대사팩, 두 캐릭터의 동시 연출, 팩 안의 실행 스크립트는 지원하지 않아요.
앱이 발생시키지 않는 새 상황 이름을 설정 파일에 적는 것만으로
새 행동이 생기는 것은 아니에요.
기본 상황 세 가지부터 만들고, 가져오기와 화면 표시를 확인하며 확장하세요.
