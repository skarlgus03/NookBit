# 분류 규칙 사용 가이드

분류 규칙은 ‘어떤 파일을 어느 폴더로 보낼지’를 정하는 약속이에요.
노드를 연결해서 만들고, 실제 이동 전에 시험할 수 있어요.

## 처음 만들어 보기

1. 캔버스의 빈 곳을 우클릭하고 **조건 → 확장자**를 추가하세요.
2. 노드를 선택하고 오른쪽 입력칸에 `png, jpg`를 입력하세요.
3. 우클릭 메뉴에서 **결과 → 목적지**를 추가하세요.
4. 파일 입력 → 확장자 → 목적지 순서로 연결하세요. 오른쪽 연결점에서 다음 노드의 왼쪽 연결점으로 드래그하면 돼요.
5. 목적지를 선택해 폴더를 지정하고 **규칙 테스트**로 결과를 확인하세요.
6. **전체 저장**을 누르면 파일 정리 페이지에서 이 규칙을 사용할 수 있어요.

규칙을 편집하거나 시험하는 것만으로 파일이 이동하지는 않아요.
파일 정리 페이지에서 미리보기와 최종 확인을 거쳐야 실제로 이동해요.

## 폴더 전체를 정리하려면

파일 정리 페이지에 폴더를 놓으면 폴더 전체가 하나의 대상이 돼요.
우클릭 메뉴의 **조건 → 파일 / 폴더 구분**을 추가하고 **폴더만**을 고르세요.
파일 입력 → 대상 종류(폴더만) → 목적지를 연결하면 폴더만 정리할 수 있어요.
대상 종류 뒤에 **이름 포함**이나 **수정 경과일** 조건을 이어도 돼요. 내부 파일은 따로 분류하지 않으며,
확장자·파일 크기 조건은 폴더에 적용하지 않아요. 폴더와 그 안의 파일을 동시에 넣을 수는 없어요.
파일을 옮기는 다른 가지나 전체 예외가 있다면 파일도 그 규칙으로 분류될 수 있어요.
폴더만 옮기려면 그런 가지를 끄거나 파일을 **정리 제외**로 연결하세요.
목적지에 같은 이름의 파일이나 폴더가 있으면 그 폴더만 그대로 남겨요.
폴더끼리 합치거나 덮어쓰지 않으며, 나머지 대상은 계속 정리해요.

## 폴더 안의 파일을 각각 정리하려면

1. 캔버스를 우클릭하고 **새 흐름 → 폴더 내용물 정리**를 추가하세요.
2. **내부 파일 순회** 노드를 골라 **바로 안의 파일만**, **모든 하위 폴더**, **하위 폴더 단계 지정** 중 하나를 고르세요.
3. **전체 저장**을 누른 뒤 파일 정리 대기 목록에서 해당 폴더에 적용할 흐름을 선택하세요.

단계를 `1`로 지정하면 선택한 폴더 바로 안의 파일과 한 단계 아래 폴더의 파일을 포함해요.
**분류 흐름 호출**에서 기본 정리나 별도 분류 흐름을 선택할 수 있어요.

## 조건과 결과를 연결하기

- **조건**에는 파일·폴더 구분, 확장자, 크기, 이름 포함, 수정 경과일, 원본 경로가 있어요.
- **그 외 (예외)**는 같은 부모 아래에서 활성화된 조건이 모두 맞지 않을 때 선택돼요.
- **결과**에서는 **목적지**로 보내거나 **정리하지 않음**으로 끝내요.

여러 조건을 모두 만족하게 하려면 자식으로 연결하세요.
예를 들어 크기 ‘5MB 초과’ → 확장자 ‘png, jpg’ → 목적지를 연결하면,
5MB를 넘는 PNG 또는 JPG만 해당 목적지로 분류해요.

AND·OR·NOT을 쓰려면 조건 노드의 출력을 논리 노드의 **네모 입력**에 연결하세요.
조건 계산 선은 점선으로 표시돼요. **둥근 연결점**으로 파일 입력과 다음 분류 단계를 연결하세요.
AND는 모든 입력이 맞을 때, OR는 하나 이상 맞을 때, NOT은 연결한 조건 하나가 틀릴 때 통과해요.
예를 들어 `PNG AND NOT(이름에 ‘임시’ 포함)`은 임시 이미지를 뺀 PNG를 골라요.

## 어떤 가지가 먼저 선택되나요?

같은 부모에 연결된 조건은 표시된 **1, 2, 3 순서**로 검사해요.
그중 처음 맞는 가지 하나만 선택하고 아래로 내려가요.
노드의 화면 위치나 높이는 검사 순서가 아니에요.

한 가지를 선택한 뒤 자식 조건이 맞지 않아도 이전 형제 가지로 되돌아가지 않아요.
‘그 외’는 같은 부모 아래에 하나만 둘 수 있어요.

- 목적지까지 도달: 해당 폴더로 분류돼요.
- 정리 제외까지 도달: 이 파일은 정리하지 않아요. ‘미분류 폴더’로 옮기는 뜻이 아니에요.
- 끝까지 맞는 규칙이 없음: 미분류로 남아요. 전체 예외 목적지가 설정돼 있다면 그 목적지를 사용해요.

목적지 없이 끝난 가지는 작성 중인 불완전한 규칙이에요.
일부러 이동하지 않으려면 **정리 제외** 노드로 끝내세요.

## 목적지 폴더 지정하기

경로를 직접 입력하거나 붙여넣어도 되고, **폴더 선택…**으로 찾아도 돼요.
입력칸 아래의 **실제 경로**를 확인하세요.

- **기본 정리 폴더 기준** 체크: `사진/여행`은 기본 정리 폴더 아래의 사진/여행 폴더예요.
- 체크 해제: `D:/중요자료`처럼 전체 경로를 지정해요. 다른 드라이브도 사용할 수 있어요.

기본 정리 폴더는 파일 정리 페이지에서 지정하는 기준 폴더예요.
윈도우 사용자 폴더를 자동으로 뜻하는 것은 아니에요.

외부 폴더를 선택하면 사용 허용을 물어요. 경로를 붙여넣었다면
**이 외부 폴더 허용…**을 누르세요. 허용한 폴더와 그 아래 폴더만 사용할 수 있어요.
설정 페이지의 **허용한 외부 목적지**에서 허용을 해제할 수 있어요.
규칙 JSON을 불러오는 것만으로 외부 폴더 사용이 허용되지는 않아요.
드라이브 전체나 앱 데이터 폴더를 정리 대상으로 사용할 수 없어요.

## 저장·불러오기·시험하기

**전체 저장** 전의 변경은 초안이에요. 실제 정리는 마지막으로 저장한 규칙을 사용해요.
**파일 → JSON 불러오기**나 **JSON 내보내기**를 사용하세요.
불러올 때 자동으로 검증하며 잘못된 파일은 현재 규칙을 대체하지 않아요.
저장하지 않은 초안이 있다면 교체 전에 확인을 물어요.

**편집 → 규칙 검사**에서 잘못된 연결과 도달할 수 없는 가지를 확인하세요.
구조 오류가 있으면 저장이 막혀요. 조건 모순이나 앞 조건에 완전히 가려진 가지는 경고로 표시돼요.
오류나 경고 항목에 노드가 표시되면 눌러서 그 위치로 이동할 수 있어요.

**규칙 테스트**에서 실제 파일이나 가상 파일 하나로 기본 정리 결과를 확인하세요.
**조건별 결과 보기**에서는 검사한 조건의 일치·불일치와 AND·OR에서 검사 생략된 입력을 확인할 수 있어요.
목록에서 조건을 누르면 캔버스의 해당 노드로 이동해요.
AI가 만든 규칙은 불러오기 → 규칙 검사 → 규칙 테스트 → 전체 저장 → 파일 정리 미리보기 순서로 확인하세요.

## 캔버스 조작

- 빈 곳 우클릭: 노드 추가 메뉴. 우클릭 드래그: 화면 이동.
- 마우스 휠: 확대·축소. 규칙을 불러올 때 기본 배율은 100%예요.
- 빈 곳 좌클릭 드래그: 여러 노드 선택. 선택한 노드 드래그: 이동.
- Delete: 선택한 노드 제거. 파일 입력 노드는 제거할 수 없어요.
- Ctrl+C / Ctrl+V: 선택한 노드 복사·붙여넣기.
- Alt를 누르고 연결선 클릭: 강조된 선 끊기.
- **노드 전체 보기**: 모든 노드가 보이도록 화면과 배율을 맞춰요.

문제 해결이 어려우면 작은 규칙부터 만들어 시험해 보세요.
처음에는 중요 파일 대신 복사해 둔 시험용 파일을 사용하는 것이 좋아요.
