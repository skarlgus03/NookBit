# 컴패니언 말풍선 표시 규격

## 현재 구현

바탕화면 `CharacterBubble`과 관리 페이지 미리보기는 동일한
`CharacterBubbleView`를 사용한다. 미리보기 문구는 테스트 전용이며
정리 제안이나 실제 파일 작업을 발생시키지 않는다.

모든 표시 치수는 Qt 논리 좌표이다. 캐릭터 배율은 부착점 위치에만
적용하며 말풍선 글자 크기를 함께 줄이지 않는다.

| 항목 | 기본값 |
| --- | --- |
| 글자 크기 | 16 |
| 기본 말풍선 전체 최대 너비 | 320 (본문 폭은 좌우 여백을 제외) |
| 본문 여백 | 좌우 및 위쪽 14 |
| 최대 줄 수 | 4, 초과 시 말줄임 |
| 화면 가장자리 여백 | 8 |
| 높이 | 내용에 맞춰 계산, 기본 스킨 최대 168 이내 및 화면 영역 제한 |

규격은 `UiMetrics.qml`에서 관리한다. 글자별 사용자 배율, 긴 대사의
더 보기 UI는 아직 제공하지 않는다. 화면이 작으면 영역 제한을 우선한다.
스크린 경계에서 방향을 바꾸거나 화면 안으로 옮기므로 꼬리 끝과
캐릭터 부착점이 완전히 일치하지 않을 수 있다.

## 이미지팩 호환

- 기본 스킨: QML 배경과 꼬리, 앱이 본문과 동작 버튼을 별도로 표시.
- PNG 스킨: 기존 ImagePack v1의 `bubble.skin.kind: image`를 유지.
  `sources`에 전체 PNG를 선언하고 `sourceId`로 참조한다.
- PNG 원본 해상도는 자유이며 `size`로 논리 표시 크기를 지정한다.
  너비 100~1024, 높이 64~1024. 투명 배경을 권장하며 글자는 그리지 않는다.
- `textRect`와 `actionRect`는 스킨 내부 논리 좌표이다. 영역은 서로
  겹치지 않고 스킨 안에 들어가야 한다. 최소 크기는 각각 32×20이다.
- PNG는 고정 크기 스킨이며 작은 표시 영역에서는 전체를 축소한다.
  9분할이나 꼬리 분리는 아직 지원하지 않는다.
- 커스텀 스킨 글자는 현재 밝은 색으로 표시하므로 어두운 본문 배경이 필요하다.
- `bubble.pivot`은 꼬리 끝 등 말풍선 내부 기준점의 정규화 좌표이다.
  `bubble.attachment`는 캐릭터 피벗 기준의 논리 좌표이다.
- PNG 디코딩 실패 시 기본 배경으로 대체한다.
- SVG는 현재 지원하지 않는다. `.svg` 파일을 PNG 소스로 선언해도 사용할 수 없다.

상세 JSON 규격은 [ImagePack v1](imagepack-v1.md)을 따른다.
이번 변경은 새 JSON 필드를 추가하지 않는다.

## 후속 검토

긴 대사 전체 보기, 사용자 글꼴 배율, PNG 9분할 및 독립 꼬리,
SVG의 지원 요소와 검증 정책은 별도 구현과 호환성 검토 후 규격에 추가한다.
