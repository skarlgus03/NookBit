# 분류 규칙 트리 v2

`resources/rules/tree.example.json`은 새 형식의 예제다. `nodes` 배열의 순서는
형제 규칙의 우선순위다. 각 높이에서 활성화된 일반 조건을 위에서부터 검사하고,
처음 일치한 가지 하나만 따라간다. 다른 형제로 되돌아가지 않는다.

같은 높이의 `otherwise: true` 노드는 일반 조건이 하나도 맞지 않을 때의
`else`다. 한 높이에 하나만 둘 수 있다. 조건이 맞는 가지에 들어갔지만
자식 중 맞는 노드가 없거나, 도착한 리프에 목적지가 없으면 미분류다.
`globalOtherwise`가 있으면 그 마지막 미분류 결과에 적용한다. 설정하지
않으면 파일을 대기 목록에 남긴다.

목적지는 리프의 `destination.path`에만 둔다. 조건 경로를 거칠 때 폴더
이름을 누적하지 않는다. 현재 v2는 기존 안전 정책과 동일하게 정리 기준
폴더 아래의 상대 경로만 허용한다. 기준 폴더 밖의 목적지를 허용하는 설정은
아직 구현하지 않았다.

`when` 객체 안의 필드는 모두 만족해야 한다. `extensions`와
`fileNameGlobs` 배열은 각각 항목 중 하나가 맞으면 된다. `minimumBytes`는
이상(`>=`), `maximumBytes`는 이하(`<=`), `greaterThanBytes`는 초과(`>`)
조건이다. 예를 들어 20 MiB 초과는 `20971520`바이트를 지정한다.
규칙 ID는 트리 전체에서 유일해야 한다. 최대 깊이는 32, 최대 노드 수는
1000으로 제한한다.

v1 규칙은 계속 읽을 수 있다. v2를 사용하는 곳에서는
`schemas/rules-tree.schema.json`으로 검증한다. 화면의 규칙 편집·저장과
기본 규칙의 v2 전환은 아직 하지 않았다.
