## 추가 검증과 남은 범위

부분 복사를 보존하는 되돌리기는 `--preserved-undo-run`으로 실행한다. 2026-10-05 실제 되돌리기·원본/임시 보존·감사 실패·변경/교체 차단·복원 도중 충돌과 SQLite 재열기 6개가 통과했다. 보고서는 `preserved-undo-report.json`이며 [복구 계약](interrupted-operation-recovery.md)의 부분 보존 되돌리기 검증을 따른다. 이 모드도 새 고유 자료만 사용하고 프로세스를 강제 종료하지 않는다. 파일 작업 잠금을 공유하므로 CTest와 수동 실제 볼륨 시험은 동시에 돌리지 않는다.

명시적 전체 재개·되돌리기는 `--recovery-run`으로 실행한다. 2026-10-05 실제 두 볼륨의 실행 중단/선택 처리 10개 시나리오가 통과했으며 결과는 `recovery-report.json`에 남는다. 범위·실행 증거·부분 전송의 차단 정책은 [전체 작업 복구](interrupted-operation-recovery.md)의 전체 선택 실행 검증을 따른다. 이 모드는 시험 예외로 단계 사이에서 중단하며 프로세스를 강제 종료하지 않는다. 다른 모드와 마찬가지로 새 고유 자료만 만들고 보존한다.

후속 [중단 작업 조회 백엔드](interrupted-operation-recovery.md)는 실제 혼합 배치 중 2개 이동 완료·1개 대기 상태를 읽고 SQLite를 변경하지 않는 것까지 확인했다. 전체 복구 실행이나 혼합 배치 강제 종료 시험과는 구분한다. 새 자동 진단 테스트를 포함한 현재 자동 테스트 묶음은 19개다.
